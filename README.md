Курс по машинному обучению был рассчитан на нас, кто ещё не прикасался к данной и подобным дисциплинам

Целью было познакомить нас с используемыми методами из основных библиотек и подходом к предобработке данных и запуске обучения модели

Формой отчётности являлись лабораторные работы, код по которым показывался преподавателю и описывался своими словами, далее ответы на вопросы преподавателя

Явно использовали знания, полученные по другим предметам 
(Теория вероятностей и математическая статистика, Методы оптимизации, Математический анализ) 
для корректного формального объяснения тем
